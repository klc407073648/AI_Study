加盐的加密（salted hashing）是指在计算散列值之前，在原始密码的基础上加上一段随机字符串（即盐值）。这样做可以增加密码哈希的安全性，防止彩虹表攻击（预先计算好的哈希值对照表）。当你需要验证用户输入的密码是否正确时，你需要进行以下步骤：

# 加盐哈希校验步骤

* 存储哈希和盐：
    * 当用户首次设置密码时，你需要生成一个随机的盐值，并且使用这个盐值与用户的密码一起生成哈希值。
    * 这个盐值和哈希值应该存储在数据库中，而不是密码本身。
* 用户登录时：
    * 用户输入他们的密码。
    * 从数据库中检索该用户的盐值。
    * 使用相同的算法和检索到的盐值来重新计算输入密码的哈希值。
* 比较哈希值：
    * 比较用户输入密码生成的新哈希值与存储在数据库中的哈希值。
    * 如果两个哈希值匹配，则认为用户输入的密码是正确的；否则，密码错误。


下面是一个简单的Python示例，演示如何使用hashlib库来生成加盐的哈希值，并在用户登录时验证密码。

```python
import hashlib
import os

# 生成随机盐值
salt = os.urandom(16)

# 假设这是用户的密码
password = "your_password"

# 创建加盐哈希值
salted_password = salt + password.encode()
hashed_password = hashlib.sha256(salted_password).hexdigest()

# 存储盐值和哈希值
stored_salt = salt
stored_hash = hashed_password

# 用户尝试登录时验证密码
def verify_password(attempt_password, stored_salt, stored_hash):
    attempt_salted_password = stored_salt + attempt_password.encode()
    attempt_hash = hashlib.sha256(attempt_salted_password).hexdigest()
    
    return attempt_hash == stored_hash

# 假设用户输入了密码
user_attempt = "your_password"

# 验证密码
is_valid = verify_password(user_attempt, stored_salt, stored_hash)

if is_valid:
    print("Password is valid.")
else:
    print("Password is invalid.")
```
